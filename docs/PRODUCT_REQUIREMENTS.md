# Product requirements

Orbit helps students discover campus events, find teammates, and build profiles. Organizers publish events and manage registrations. MVP goals and out-of-scope features are defined in [the full implementation plan](IMPLEMENTATION_AND_ARCHITECTURE.md).

The iOS shell exposes the five student destinations: Discover, My Events, Find Team, Inbox, and Profile. Discover is the first functional vertical slice; other destinations are labeled scaffolds.
