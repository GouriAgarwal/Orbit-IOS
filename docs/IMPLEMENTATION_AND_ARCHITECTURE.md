# Orbit — Implementation & Architecture Plan

This is the product specification supplied for the Orbit MVP. The proposed product scope, architecture, data model, API outline, roadmap, security principles, and open production decisions are preserved in the source plan. The implementation in this repository is an initial scaffold and first discovery slice; it does not claim that every roadmap capability is complete.

The MVP centers on campus event discovery and registration, organizer event management, and student team discovery. It uses SwiftUI + MVVM on iOS and a modular NestJS API with PostgreSQL/Prisma. See the source specification for full requirements and staged acceptance criteria.
